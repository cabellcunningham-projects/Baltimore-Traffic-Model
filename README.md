# Baltimore Traffic Simulation: Francis Scott Key Bridge Collapse

## Project Overview

This project uses Python to model the impact of the Francis Scott Key Bridge collapse on Baltimore's transportation network.

The simulation compares traffic conditions under two scenarios:

1. **Baseline Scenario:** Baltimore's road network with the Key Bridge operational.
2. **Disrupted Scenario:** The road network following the bridge closure, with additional penalties applied to tunnel routes to represent freight restrictions.

The objective is to estimate how a major infrastructure disruption affects traffic congestion, vehicle travel time, and traffic redistribution across surrounding roadways.

## Methodology

The model uses several computational techniques:

- **NetworkX:** Represents Baltimore's road network as a directed graph of intersections and road segments.
- **OpenStreetMap Data:** Provides roadway characteristics, including segment lengths, speed limits, and lane counts.
- **Bureau of Public Roads (BPR) Function:** Estimates travel times based on roadway congestion.
- **Method of Successive Averages (MSA):** Iteratively assigns traffic demand to routes based on estimated travel times.
- **Scenario Comparison:** Evaluates changes in traffic volumes and vehicle-hours traveled after the simulated disruption.

## Project Files

- `ModelForBaltimore1.py` — Builds the road network, performs traffic assignments, simulates the bridge closure, and calculates traffic impacts.
- `Graphofbaltimoretraffic.py` — Generates a visualization of the ten roadway corridors with the largest positive traffic-volume changes.
- `edges_all.csv` — Road network dataset, available separately through Google Drive.
- `part1_traffic_impact_results.csv` — Output generated by the simulation, containing baseline and disrupted traffic volumes.

## Running the Simulation

### 1. Install Python Dependencies

```bash
pip install pandas numpy networkx matplotlib
```

### 2. Download the Dataset

Download `edges_all.zip` using the link above.

Extract `edges_all.csv` and place it in the same folder as the Python scripts.

### 3. Run the Traffic Model

```bash
python ModelForBaltimore1.py
```

The program simulates both traffic scenarios, calculates network metrics, and generates `part1_traffic_impact_results.csv`.

### 4. Generate the Visualization

```bash
python Graphofbaltimoretraffic.py
```

This produces a horizontal bar chart showing the ten roadway corridors with the largest increases in modeled traffic volume.

## Model Limitations

This project is a simplified traffic-network simulation rather than a calibrated traffic forecast.

- Origin-destination demand is generated from selected network nodes rather than observed travel patterns.
- Missing speed limits and lane counts are assigned default values.
- Tunnel restrictions are represented using increased travel-time costs.
- Results depend on the road network data, assumed demand, and model parameters.

The results should therefore be interpreted as exploratory estimates of potential traffic redistribution, not measured traffic impacts.
